빠른 등록Quick setup

DSM에 패키지 소스 추가하기Add the package source to DSM

  1. 1

    패키지 센터 열기Open Package Center

    DSM 메인 메뉴에서 패키지 센터를 실행합니다.Open Package Center from the DSM main menu.

  2. 2

    패키지 소스 설정으로 이동Open Package Sources

    패키지 센터의 설정에서 패키지 소스 탭을 선택하고 추가를 누릅니다.In Settings, select the Package Sources tab and click Add.

  3. 3

    이름과 위치 입력Enter the name and URL

    이름은 PeterSuh-Q3, 위치는 위의 URL을 입력한 다음 확인을 누릅니다.Enter PeterSuh-Q3 as the name and the URL above as the location, then click OK.

  4. 4

    커뮤니티 패키지 확인Browse community packages

    패키지 센터의 커뮤니티 탭을 열면 이 소스에서 제공하는 호환 패키지가 표시됩니다.Open the Community tab in Package Center to see compatible packages from this source.

SPK 파일은 각 패키지의 공개 GitHub 릴리스에서 내려받습니다. 표시되는 패키지와 빌드는 NAS 모델, CPU 아키텍처, DSM 버전에 따라 달라집니다.SPK files are downloaded from each package's public GitHub releases. Available packages and builds depend on your NAS model, CPU architecture, and DSM version.
